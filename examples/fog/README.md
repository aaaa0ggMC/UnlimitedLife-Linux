# Fog 方块岛场景

## 交互式原理讲解

用浏览器直接打开 [docs/fog-explained.html](docs/fog-explained.html)（单文件、无外部依赖）：
从 Beer–Lambert 到对数深度切片、密度场、HG 相函数、三阶段 compute 和片元部分段重建，
每节都对应本目录的真实代码，并带可拖动的 Canvas 演示。

从主项目目录执行：

```sh
xmake build fog
xmake run fog
```

## 键位

- **M 锁定鼠标后才允许移动视野**（未锁定时视角不动，避免与 ImGui 抢鼠标）
- WASD 沿相机朝向移动
- Space/E 沿世界 +Y 上升，左右 Shift/Q 沿世界 -Y 下降
- 默认鼠标灵敏度为 0.065 度/像素
- M 切换鼠标锁定
- B 切换 Blinn-Phong 高光
- ESC 退出。
- 雾没有距离终点；旧滚轮/R/T 截断控制已移除
- G/F 调整可选的全局近端裁剪距离（需在雾面板开启裁剪）
- `Left` / `Right` 调雾的呼吸周期（Left 变快 / Right 变慢，每次 *0.8 / *1.25，范围 5-900 s）
- `F1` 显示/隐藏 ImGui 界面（单窗口；面板平铺在菜单栏上，不堆叠多窗口）
- 菜单栏直接平铺切换（当前面板高亮）：
  - **统计**：帧率、实体/实例数、全部快捷键说明、界面缩放
  - **雾**：密度场（sigma_base / sigma_mist / 高度衰减 / 参考面 / 噪声频率、强度 /
    呼吸周期、动画幅度、行波频率）、雾色与可选近端裁剪 start
  - **光照**：太阳色/方向/环境光/高光
  - **天空**：曝光
  - **检查器**：列出所有实体与它们的组件字段（Transform / SurfaceMaterial / CameraTilt /
    Projector / FogParams / Skybox / DirectionalLight 等），改动直接写回组件内存；改到走实例批的部件时
    会自动重传实例缓冲（`App::refresh_instances()`）
- 界面整体按 `ui.scale`（默认 1.25）放大：字体与内边距一起乘
- 统计面板里可调：**窗口背景不透明度**（0 = 只留控件，能完全透出后面的场景）与**控件不透明度**；
  两项都是本会话内生效（重启回到默认）

## 配置

### 场景菜单

窗口菜单栏的「场景」页集中选择预设，不再叠加在雾面板顶部：

- **默认**：保留当前配置和已有局部雾；首次切换前的状态就是默认页起点。
- **局部白雾**：极淡全局雾，两团偏白的控制点雾在岛上周期翻涌。
- **贴地晨雾**：低矮、缓慢运动的雾带，配合柔暖晨光，保留上方能见度。
- **暖光迷雾**：暖色低角度太阳与火把/灯笼点光，照亮运动中的局部雾团。
- **日出云海**：低背景雾 + 分散在桥、龙像、房屋附近的多团暖色局部云带。
- **风暴云海**：暗色低云快速横移，风速/动画周期更激进，保留火把作尺度参照。
- **黄昏云河**：细长暖色云带高速横穿岛屿，强前向散射。
- **月夜流雾**：冷色薄云配火把/灯笼，动画最慢但局部翻滚最明显。

每页的雾、光照、显示设置和局部雾编辑会在本次会话内保留，返回时恢复动画相位；仅在切换时应用，不会每帧重置参数。相机位置与场景几何共用，便于同视角对比。预设不会写配置文件；「保存局部雾」仍只保存当前页的局部雾，不包含整套光照／全局雾设置。云海页使用极低背景雾 + 4–5 个分离的局部控制点云带；每团云带独立翻涌，经过火把/灯笼时会形成明显的光晕与遮挡，而不是整屏均匀起雾。

预设场景由 `app_presets.cpp` 构建；新增/云海回归位于 `editor-check` 子命令。

```json
{
    "fog": {
        "r": 0.55, "g": 0.68, "b": 0.78,
        "start": 8.0,
        "density": 0.05, "mist_density": 0.02,
        "height_falloff": 0.35, "ground_y": -0.5,
        "noise_scale": 0.09, "noise_amount": 0.5
    },
    "shape": {"path": "test_data/dragon.obj"},
    "sky": {"texture": "", "exposure": 1.0},
    "lighting": {"ambient": 0.24, "specular": true}
}
```

## 水面与树叶

- 水面使用独立半透明批次：在不透明几何和天空之后按 `SRC_ALPHA / ONE_MINUS_SRC_ALPHA` 混合，不写深度；水块不进入 shadow pass。
- 从水上/水下只保留朝向相机的一侧水面（顶面或底面），丢弃侧面，避免半透明水在每一格边界叠加出方块网格。
- 细法线来自 `textures/water_normal.png`（可平铺噪声法线），shader 用两层不同尺度和流速采样，再叠加低频 `sin` 波；`build_shaders.sh` 会把 `textures/` 同步到 `assets/fog/textures/`。
- 水面用菲涅耳混入 `atmosphere_color()` 天空反射；点光和太阳高光随法线变化。水面不透明度可在「光照 → 表面」里调。
- 方块法线：草顶/草侧/石/木/叶/沙/瓦共 7 张预生成 256² 可平铺法线（`tools/gen_block_normals.py`），按材质名绑定；shader 用世界空间 UV 和面切线基采样，每片元只多一次 `texture()`，远处按距离衰减。场景 JSON 不需要新增字段，未知材质默认不加法线。
- 树叶使用 8×8 UV 网格挖洞（`discard`）和整块刚性摆动；阴影 pass 仍按实心叶块处理。

## Froxel 体积雾

渲染已切换为 GPU compute 驱动的视锥体积雾，不再使用下面归档的解析雾模型。

- 网格：默认每 8×8 屏幕像素一列，上限 192×128；深度默认 64，支持 16–96 个对数体元。
- 世界空间三维噪声、风向平移、呼吸和行波形成密度场，包含浓雾、团雾、高空层雾三个预设。
- 太阳与火把/灯笼点光注入单次散射；HG 各向异性、反照率与入射光的介质衰减均可调整。
- 太阳 2048² 正交阴影 + 最近 5 盏点光的 6×512² cube shadow，使用实际场景几何（含实例块与模型），同时影响表面和雾；表面使用 5×5 PCF，体积积分保持 3×3 以控制成本。
- 三阶段 compute：局部系数注入 → 历史重投影与过滤 → Beer–Lambert 前向积分。历史累积的是局部散射系数和消光，不是相机射线的积分结果。
- 每个交换链图像独占原始系数、双缓冲历史和积分 SSBO，fragment 手动三线性采样 RGB 散射和 A 透过率。
- 几何和天空合成反射项 `background * T + scattering`，密度、颜色、可选近端裁剪和动画控件继续生效。
- 反射和散射在线性 HDR 数值域计算，之后曝光和映射至 SDR；自发光采用下面单独的显示合成，避免浓雾中的 HDR 白点。
- 窗口重建时重建网格与描述符；compute → fragment 显式内存屏障；支持 dynamic/legacy 两种渲染后端。
- 历史过滤包含视锥/深度越界拒绝、相机突变拒绝、参数/实例修改失效、历史年龄衰减、六邻域裁剪及密度/光照变化响应；首帧不读取未初始化历史。
- 统计面板显示体积 SSBO 逻辑大小及 shadow/inject/temporal/integrate/scene+UI 分段 GPU timestamp；不等待 query，不把 CPU 帧率当作 GPU 体积耗时。
- 当前仍是单次散射近似；没有多次散射、CSM、水下折射或透明材质投射的阴影。水块不进入太阳/点光 shadow pass。
- 需要所选 graphics 队列同时支持 compute；否则启动时给出明确错误。

实现：`app_volume.cpp`、`shaders/froxel*.comp`、`shaders/lighting.glsl`；AVE 的 `GraphicsContext::begin`
新增可选的 `before_render` 回调，用于在渲染作用域外录制 compute 命令。

### 控制与使用

- **雾面板**：天气编号 `0=自定义 / 1=浓雾 / 2=团雾 / 3=高空层雾`；切换时应用参数一次，之后仍可微调。回到 0 保留当前参数，不恢复出厂值。
- **全局近端裁剪默认关闭**：全局介质连续到相机，不再默认挖掉前 8 单位。兼容配置中的 `start` 数值仍保留，仅勾选「启用全局近端裁剪」后生效；局部 FogVolume 不受此开关裁剪。
- 同面板可调网格像素步长、深度切片、历史权重、抖动、HG、反照率、入射光步数和雾层位置。
- 网格控制会等待设备空闲并重建体积资源；不在每次修改时重新编译阴影管线。
- **光照面板**：太阳/点光阴影开关、比较偏移、法线偏移、太阳覆盖半径；点光源逐灯开关、颜色、强度、范围、半径；表面面板控制树叶摇摆、水面法线强度和水面不透明度。
- 界面按小节标题分组；`start` 仅在勾选全局近端裁剪后出现，高空雾层参数仅在天气 = 3 时出现，避免长期显示无效滑杆。
- 灯现在是有限半径的可见球形发射体，不投几何阴影；其亮度、照明和雾散射共用光强与半径，不再使用独立的 emission=1/3 预览常数。
- **灯核是均匀自发光**：聚光锥只调制射入介质／表面的光束，从锥外看灯仍是亮的灯泡，不会变成黑球。
- **自发光显示**：先压缩自发光的显示增量，再在线性显示空间乘雾透过率，最后做 sRGB 编码。
  灯核和普通材质 emission 都不会再靠数千倍 HDR 峰值在浓雾里维持白点；真实照明光强、体积散射和无雾外观不变。
  这是有意采用的显示效果，不是严格的单次物理 HDR 合成。
- 所有表面（含灯核）统一积分到自身位置，Froxel 自动覆盖相机可见范围，不再有 `end` 介质终点。
  天空按光学收敛继续积分，并每列缓存额外天空层。旧 JSON 的 `fog.end` 仅兼容读取、不生效。
  相机 `far` 仍是几何裁剪面，不是雾结束位置；无雾时不人为按距离调暗辐射亮度。
- 聚光锥边缘的半影宽度取 `max(froxel footprint, 发射体半径)/距离`，近处体元小于发射体时也不会被单次采样切成硬边。
- **统一 HDR 色调映射／统一曝光 EV** 位于雾面板，可关闭映射作截白对比。光照面板另可调两灯的发射体半径。
- **调试编号**：`0=完整合成 / 1=透过率 / 2=散射 / 3=表面太阳阴影`。
- **近灯表面精细积分（边界纠偏）**：局部雾与表面所在体元相交时，复用 Froxel 积分前缀，仅对最后一格积分到表面，减少整格均值带入表面后的雾；默认开启，可关闭作 A/B。局部段使用 2 段 × 4 次基础采样，另按雾体边界细分，不再逐像素执行全程 48 段积分。接近体元末端时平滑回到缓存积分，避免跨格跳变；前缀仍为 Froxel 近似，不等同于全程精细参考积分。
- 新控制只在当前会话生效，不改变已有 `config.fog.json` 的 schema。

### App 内编辑与性能档位

- **雾面板**：添加盒形／纹理椭球雾，保存／载入局部雾；载入前需确认，会替换全部局部雾。
  存档是运行目录（通常为 `assets`）下的 `fog-local.json`，再次保存会把上一份保留为 `.bak`；
  不覆盖 `scene.json`，也不保存几何、全局雾、灯光或相机。重启后手动载入。
- **检查器**：展开任意局部雾实体，可复制（偏移 1 米）、移到视线前、让相机移近或确认删除。
  参数仍直接编辑真实 ECS 组件；最多保留 16 个局部雾实体，含禁用项。
- **动画**：时域小节可暂停雾动画；单步按钮暂停并推进一个 `1/120s` 世界 tick，不暂停相机。
- **质量档位**：性能／均衡／精细分别设置像素步长 `16/8/4`、深度切片 `32/64/96`、
  入射光步数 `2/4/8`。只是快捷组合，不锁定其他选项；网格改变会等待 GPU 空闲重建资源。
- **重复工作减少**：静态阴影按交换链图像复用，几何或灯光投影改变再重绘；局部雾参数仅变化后上传；
  空散射介质跳过照明；检查器未打开时不再构造全场组件字段。不保证固定比例的 FPS 提升。
- 无窗口回归：`fog editor-check` 检查局部雾编辑与 JSON 往返、错误输入保护、暂停／单步、
  阴影缓存条件及 ImGui ID／折叠逻辑；不等同于完整窗口交互或 Vulkan 阴影图复用验收。

详细方案、时域限制和桌面评估流程见 [体积雾实现说明](VOLUME.md)。

### 局部点光与阴影

- `scene.json` 新增可选 `lights` 数组：火把与桥上的青色灯笼各是一盏点光（`pos`、`color`、`intensity`、`range`、`radius`、`shadow`）。
- 每帧为最近的 `4` 盏点光渲染 **cube shadow**（6×512²，按交换链图像缓存）；其余点光只照明。
- 每个 froxel cell 计算光源位掩码（`light_cull.comp`），体积注入只遍历与该 cell 相交的点光；点光同时参与表面直接光、雾内散射和介质可见度，和雾气联动。
- 光照面板「点光源」分组可整体开关点光、开关点光阴影，并逐灯调整开关/颜色/强度/范围/半径，便于对比。
- 自发光方块（火把焰、灯笼玻璃）不写入阴影图，避免点光被自己的发光几何挡住。
- `cubes[]` 支持可选 `shadow: false`；贴着光源的火把杆用它关闭投影，避免灯正下方出现硬阴影。

无雾时没有体积光晕是正常的，发射体本身仍应明亮；本例不添加屏幕空间 bloom 来冒充雾。
无窗口 GPU 回归：在 assets 目录运行 `../build/linux/x86_64/debug/fog radiance-check`，不加载场景或启动窗口。

### ECS 局部雾

- 新增 `Transform + FogVolume`，支持盒形和椭球形；可选 `FogDensityTexture` 提供真正的 3D 密度纹理。
- 雾面板可直接「添加盒形局部雾」「添加纹理椭球雾」，生成在相机前方 8 个世界单位处；在检查器的 `local-fog-*` 实体内编辑。
- `Transform.scale` 是完整尺寸，旋转由 Transform 四元数／场景 axis+angle 控制；雾体不是透明几何，不进入实例绘制或投几何阴影。
- `scene.json` 可选新增 `fog_volumes` 数组。将 [local-fog.example.json](local-fog.example.json) 的数组合入现有场景，不要用这个片段替换整个场景。
- 支持 `builtin:cloud` 或带原始尺寸信息的 raw R8 体数据；ECS 只保存资源描述，App 管理 3D 图集。最多 16 个活动雾体和 4 种纹理。
- 详细字段、叠加规则、纹理格式及限制见 [局部介质说明](VOLUME.md#ecs-局部介质)。

### 可编辑控制点雾

1. 在「雾」面板点击「添加控制点雾」，会在视线前方生成带三个控制点的雾团。
2. 打开「检查器」，展开对应 `local-fog-*` 实体及 `FogControlField`。已有局部雾也可添加此组件。
3. 增删控制点，修改各点的 `position x/y/z`（局部 `[0,1]³`）、半径、密度、柔和度；`Transform` 控制整团雾的世界位置与尺寸。零个点表示空场。
4. 用 `noise scale/strength`、`octaves` 和 `seed` 调整内部层次；勾选 `animated` 后，每点按幅度、相位与整数频率做周期运动，`period` 是整团雾的循环秒数。全局暂停和单步同样生效。
5. 使用原有「保存／载入局部雾」保存控制点和动画设置；重新载入时动画从周期起点开始。

启用的 `FogControlField` 覆盖同实体的纹理密度来源，仍使用 `FogVolume` 的颜色、密度、形状和边缘；禁用后回到原密度来源。全局雾继续叠加，若只想看新雾团，将全局 `sigma_base` 与 `sigma_mist` 设为零。

每团最多 32 点、总共仍最多 16 个局部雾实体。GPU 先生成 64³ 密度网格，再做三线性查询；静态场缓存复用，动画只重生成变化槽位。缓存采用 SSBO（非硬件 3D 纹理），每交换链图像额外预留 16 MiB 密度数据。GPU 统计的 `density+inject` 包含生成成本；开启大量动画场仍会增加开销。

完整可载入示例：[control-fog.example.json](control-fog.example.json)。它是局部雾存档，可复制为运行目录的 `fog-local.json` 后载入；也可将其 `fog_volumes` 合入场景。

本功能的源码一致性与预处理检查不等同于编译或画面验收。`editor-check` 与 `radiance-check` 子命令已提供对应回归入口，实际运行仍待验证。

## 旧解析雾模型（历史归档，不再用于渲染）

不是体积雾、也不做步进：密度是**世界坐标的解析函数**，沿视线的光学深度用闭式积分算。
关键在于**地平线处不能出现接缝**，做法是让"雾收敛到的颜色"和"同一方向的背景色"是同一个函数：

> 公式推导（从 `A = epsilon*c*l`、`A = log10(I0/I)` 到 `tau` 与 `T`）、以及每一步的近似取舍，见 `shaders/fog_common.md`；这里是给使用者看的摘要。

```
atmosphere(dir) = 地平线以上：天空渐变（天顶更深蓝）
                  地平线以下：雾海渐变（从天空的地平线色出发，往下收敛到 fog_color）
sigma(p) = sigma_mist * exp(-max(p.y - ground_y, 0) * height_falloff) * mix(1, 2*noise(p.xz), noise_amount)
tau      = int sigma ds（高度项闭式积分）    T = exp(-tau)    out = background*T + atmosphere(dir)*(1-T)
```

- **天空 pass 直接输出 `atmosphere(dir)`，不再被本地高度雾洗一遍**：
  否则天空的浓淡会随相机高度变化（站低一片糊、站高又全没），而且它和地面雾的极限色对不上，
  水平线处必然出现一条硬边。
- **地面几何的 in-scatter 就是同一方向的 `atmosphere(dir)`**：远处几何在构造上正好融进背景，
  所以地平线上下连续、没有接缝；`atmosphere` 的两个分支在 `dir.y = 0` 处取值相同（都等于天空地平线色）。
- 地平线以下是**雾海渐变**（收敛到 `fog_color`）：被雾完全挡住的背景就是雾色（你定的规则），
  但它随俯角有层次，不会变成一块平色。
- 噪声只作用于密度，且按 `1/(1+span*noise_scale)` 衰减（长射线趋于噪声均值）；
  只在几何 pass 采样（天空不需要）。
- **时间项**（`anim_period` / `anim_amplitude` / `anim_frequency`）：整片雾按周期浓淡变化：

      sigma(p, t) = anim(p, phi) * [ sigma_base + sigma_mist * exp(-k*max(p.y-ground, 0)) * noise(p.xz) ]
      anim(p, phi) = 1 + amp * [ 0.55*breath(phi) + 0.45*wave(p, phi) ]

  phi 是 CPU 按 `2*pi / 呼吸周期` 累加的相位（改周期不跳相位）。三个分量的频率比取
  **1 : sqrt(phi) : phi（约 1 : 1.2720 : 1.6180）**（无理数、彼此接近）：

      breath(phi) = 0.50*sin(phi) + 0.30*sin(sqrt(phi)*phi + 1.7) + 0.20*sin(phi*phi + 0.4)

  三个振幅接近，所以不会被单一主导频率带成"短周期"；无理比值又让三者理论上不存在公共周期，
  拍频在 **分钟量级**（默认周期 60 s 时分量是 60 / 47 / 37 s，两两拍频约 3-5 分钟）。
  `wave` 是 xz 平面上的行波，相位里再套一层慢波
  （`sin(dot(p.xz,k)*2*pi*f - sqrt(phi)*phi + 0.45*sin(dot(p.xz,k.yx)*0.59*2*pi*f + 1.09*phi))`），
  波峰波谷自己也在被调制，看起来像雾团缓慢翻滚。
  行波只作用于几何雾，**天空只取与位置无关的 `breath`**（行波在长射线上等于取均值，
  单点采样还会让天空出现格子硬边）。
- `density`（sigma_base）是**主项**（全空间体积介质）：雾量只由走过的距离决定，
  俯视和侧视在同一距离上浓度一致；`mist_density` 只是近地面的附加浓度。
  天空 pass 不受两者影响（它输出大气色本身），所以 sigma_base 调大也不会再把天空洗平。
- 以下为旧解析实现的参考数据（sigma_mist=0.25、falloff=0.35、ground_y=-0.5、旧 end=55），不代表当前 Froxel 无距离截断实现：
  飞高（20/40）仍按距离积到雾，升到层顶之上（60）才自然消失。

## 场景数据（`assets/scene.json`）

方块数量、布局、材质与 dragon 摆放全部在运行期从 `assets/scene.json` 读取，改数据不用重编译。
几何和材质结构体不提供默认值，因此其字段**必须写全**；局部雾的可选字段见上节。
缺项或类型不符由 alib5 的 validator 在启动时报出具体路径
（浮点字段必须写成 `1.0` 而不是 `1`）：

```json
{
    "materials": { "grass": {"color": [0.3, 0.58, 0.13], "specular": 0.02, "shininess": 24.0, "emission": 0.0, "voxel": 1} },
    "cubes": [
        {"tag": "terrain", "pos": [-13.0, 0.5, -16.0], "axis": [0.0, 1.0, 0.0], "angle": 0.0,
         "scale": [1.0, 3.0, 1.0], "material": "grass", "solid": true}
    ],
    "dragon": {"tag": "dragon", "pos": [0.0125, 2.132, -1.1294], "axis": [0.0, 1.0, 0.0],
               "angle": 25.0, "scale": [4.0, 4.0, 4.0], "material": "jade", "solid": true}
}
```

- `materials.<名字>`：`color`(3 浮点)、`specular`、`shininess`、`emission`、`voxel`(整数)
- `cubes[]`：`tag`、`pos`(3)、`axis`(3)、`angle`、`scale`(3)、`material`、`solid`、可选 `shadow`
- `dragon`：与 `cubes[]` 元素同构；模型没加载成功时只画基座

初始场景由 `tools/gen_scene.py` 从原先的过程式布局导出（默认写到 `assets/scene.json`，可传参指定输出）：

```sh
python3 examples/fog/tools/gen_scene.py
```
